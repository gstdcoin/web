## Practical use

| Activity | Current permission |
| --- | --- |
| Install, inspect, modify or run for a permitted noncommercial purpose | Base PolyForm rights remain available. No GSTD purchase is imposed by the additional permission. |
| Run a node, as an individual or company, and receive GSTD for funded accepted work | Permitted without separate written approval under the additional permission. No work or earnings are guaranteed. |
| Build, embed or host a commercial application or integration using the covered software and GSTD network | Permitted under the additional permission; retain its license and required notices with distributed code. |
| Charge for paid distributed network compute through the covered core or commercial extensions | The underlying compute charges settle in canonical GSTD, including when bundled with another product. Independent application fees may use another currency. See LICENSE for the canonical master and full scope. |
| Install, use local-only inference, download models, or make free requests | No token-payment requirement is added. Model and service conditions remain separate. |
| Pay blockchain transaction fees | TON or the native network asset may cover gas; it is separate from GSTD compute settlement. |
| Use an independently licensed SDK or independently implement a public API without incorporating covered code | Its own license applies. This core permission does not claim control over independent implementations or impose a GSTD requirement solely for using an Apache-2.0 SDK. |
| Other commercial distribution or hosting of the covered core outside the grant | Requires another applicable license or a separate written agreement. Existing base and independently granted rights remain intact. |

This is a guide, not a replacement for the complete license. The permission grants software rights only. It does not activate a contract, move balances, waive third-party terms, or promise payment, token value, security or availability.

## Third-party inventory and notices

The package manifests and lockfiles identify direct and transitive software dependencies. Their existing license metadata is preserved. Upstream packages retain their own LICENSE/NOTICE files and terms; the GSTD permission does not relicense them. Before redistributing a build, retain the notices required by the specific included components. A lockfile license field alone is not proof of compliance.

Models, datasets, fonts, images, copied snippets and other referenced or bundled assets also require their own license and provenance review. Hugging Face model licenses are not replaced by GSTD settlement. This change is not a completed audit of all third-party rights, and grants only rights the licensor actually controls.
