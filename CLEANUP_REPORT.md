2. **Оптимизация памяти** - настроены лимиты в docker-compose.yml
3. **Очистка файлов** - удалены неиспользуемые файлы для экономии места
4. **Проверка доступности** - сайт работает по https://gstdtoken.net

### Для стабильной работы:
1. **Мониторинг**: Используйте `./monitor-resources.sh --watch`
2. **Запуск**: Используйте `./start-optimized.sh`
3. **Очистка**: При проблемах используйте `./start-optimized.sh --clean`

### Оптимизация памяти:
- Система работает на пределе памяти (74% RAM + 73% Swap)
- Рекомендуется увеличить RAM до 2GB или оптимизировать процессы

### Безопасность:
- Сайт доступен только по домену gstdtoken.net
- HTTPS работает корректно
- Caddy автоматически управляет SSL сертификатами
