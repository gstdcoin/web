## ⚙️ Оптимизации swap

### Примененные настройки:
```bash
vm.swappiness=1                    # Минимальное использование swap
vm.vfs_cache_pressure=50           # Оптимальное кеширование VFS
vm.dirty_ratio=15                  # Быстрая запись на диск
vm.dirty_background_ratio=5        # Фоновая запись
vm.dirty_expire_centisecs=3000     # Время жизни грязных страниц
vm.dirty_writeback_centisecs=500   # Частота записи
```

### Результат:
- **Swappiness**: 10 → 1 (минимальное использование swap)
- **Более агрессивное кеширование** в RAM
- **Быстрая запись** на диск для предотвращения потери данных

sudo systemctl start gstd-optimize.timer
